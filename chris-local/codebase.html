SUMMARY30초 요약

백엔드

src/ 하나에 TypeScript 16,626 파일이 들어 있고, 실행되는 것은 게이트웨이 프로세스 한 개다. HTTP 는 node:http 원본, WebSocket 은 ws 라이브러리. Express · Hono · Fastify 를 코어에 쓰지 않는다(Express 는 플러그인 3개 전용). 기능은 extensions/ 플러그인 153개로 갈라져 있고, 실제 로드는 설정으로 고른다.

프런트

주 표면은 ui/ Control UI - Lit 3 + Vite 8, 로케일 21개, React 아님. 빌드 산출물은 ui/dist 가 아니라 dist/control-ui/ 이고 게이트웨이가 직접 정적 서빙한다. 그 밖에 네이티브 앱 4종(Swift · Kotlin · Rust), TUI, Telegram Mini App 이 같은 게이트웨이에 붙는다.

데이터 · 인프라

SQLite 전용이고 드라이버는 Node 내장 node:sqlite 하나다. better-sqlite3 · libsql 없음, Postgres · MySQL · Redis 없음. 필수 외부 서비스는 0, 기본 포트는 18789 하나. Node 22.22.3+ / 24.15+ / 25.9+ 와 pnpm 12.1.0 만 있으면 뜬다.

계층 다이어그램. 위에서 아래로 프런트 표면 → 게이트웨이 프로세스 내부 모듈 → 저장소와 외부 서비스. 점선 상자는 전부 선택이다. 근거는 각 절에 파일 경로로 붙였다.

이 문서의 규칙

모든 주장에 파일 경로(가능하면 줄 번호)를 붙였다. 수치는 이 PC 에서 직접 센 값이다. 확인하지 못한 것은 부록에 그대로 적었다. 운영 · 설치 · 동기화 절차는 포크의 FORK.md 가 정본이고, 이 문서는 코드 구조만 다룬다.

2-1. 진입점 체인

openclaw (bin) = openclaw.mjs
   ├─ Node 버전 게이트 (>=22.22.3 <23 || >=24.15.0 <25 || >=25.9.0)
   ├─ compile-cache respawn 감독 (자식 spawn + 시그널 포워딩)
   └─ import("./dist/entry.js") -> src/entry.ts -> src/cli/* -> gateway 명령

  • package.json 의 bin 이 openclaw.mjs. 순수 .mjs 라 빌드 없이도 돈다.
  • respawn 감독자가 런처 안에 있다. runRespawnedChild() 가 자식을 spawn 하고 SIGTERM/SIGINT/SIGHUP/SIGQUIT(Windows 는 SIGBREAK)를 전달한 뒤, 1초 유예 → 강제 kill → 1초 후 하드 exit 로 내려간다. 같은 로직의 TS 판이 src/entry.compile-cache.ts 에 있다.
  • 게이트웨이 시작: src/gateway/server.ts:29-36 startGatewayServer(port = 18789, opts). 무거운 구현은 동적 import 로 늦게 로드한다. 기본 포트 상수는 src/config/paths.ts:406.
