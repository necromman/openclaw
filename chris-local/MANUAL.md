# 사내 AI 비서 사용 안내 (진바이오테크)

> 이 문서는 진바이오테크 임직원이 사내 AI 비서를 쓰는 방법을 정리한 것입니다. 관리자용 내용은 8절 이후에 있습니다.\
> 제품명은 임시로 "Chris Agent" 이며 납품 전에 확정합니다. 기준일 2026-09-08.

## 1. 접속과 로그인

- 주소: `https://jinbio.botops.cloud`
- 회사 계정(이메일·비밀번호)으로 로그인합니다. 계정은 관리자가 초대해서 만들어 줍니다.
- 초대를 받으면 메일의 링크(또는 관리자가 전달한 링크)를 열어 비밀번호와 이름을 정하면 가입이 끝납니다. 링크는 72시간 동안 유효합니다.
- 비밀번호를 잊으면 로그인 화면의 "비밀번호를 잊으셨나요" 를 누르거나 관리자에게 초기화를 요청합니다.
- 로그아웃은 왼쪽 아래 내 이름 메뉴의 "로그아웃" 입니다. 로그아웃하면 열려 있던 화면도 즉시 끊깁니다.

## 2. 첫 화면 이해하기

- 왼쪽 위 "공용" 이 회사 공용 AI 비서(에이전트)입니다. 현재는 이 하나만 씁니다.
- 왼쪽 목록은 내 대화(세션) 목록입니다. 대화는 주제별로 따로 여는 것이 좋습니다.
- "홈" 은 내 기본 대화입니다. 사람마다 따로 열리므로 다른 직원이 내 홈 대화를 보지 않습니다. 주제가 바뀌면 "새 세션" 으로 나누는 것이 좋습니다(5절 참고).
- 오른쪽 아래 모델 선택에서 답변에 쓸 AI 모델을 고를 수 있습니다. 기본은 OpenAI 모델이고 Claude 모델로 바꿀 수 있습니다. 바꾼 모델은 그 대화에만 적용됩니다.

## 3. 대화하기

1. 왼쪽 "새 세션" 을 누릅니다.
2. 아래 입력창에 질문을 쓰고 Enter 를 누릅니다. 줄을 바꾸려면 Shift+Enter 입니다.
3. 답변이 길면 "생성 중지" 로 멈출 수 있습니다.
4. 대화 제목은 첫 질문으로 자동으로 붙고, 제목을 눌러 바꿀 수 있습니다.

질문 요령

- 배경을 한 문장 넣으면 답이 정확해집니다. 예: "품질팀 월간 보고서 초안입니다. 표 형식으로 정리해 주세요."
- 문서를 다룰 때는 파일을 첨부하고 "이 파일을 요약해 줘" 처럼 파일을 가리켜 말합니다.

## 4. 파일 첨부와 다시 찾기

- 입력창 왼쪽 "+" 로 파일(PDF·Word·Excel·PowerPoint·이미지)을 첨부합니다. 파일 하나당 20MB 까지입니다.
- 첨부한 파일은 회사 서버에 보관되고, 같은 대화를 다시 열면 그대로 보입니다.
- 나중에 다른 대화에서도 다시 부를 수 있습니다. "내가 올린 파일 목록 보여 줘" 라고 하면 목록이 나오고, "그중 두 번째 PDF 요약해 줘" 처럼 이어서 쓰면 됩니다.
- 내가 올린 파일은 나와 관리자(그리고 읽기 전용인 임원)만 볼 수 있습니다. 같은 부서 동료라도 볼 수 없습니다.
- 파일은 자동으로 지워지지 않습니다. 대화를 삭제해도 파일은 서버에 남습니다(관리자가 보관 정책을 정합니다).

## 5. 개인 대화와 공유 범위

- 기본 설정은 "본인만 보임" 입니다. 직원과 중재자는 자기가 만든 대화만 보고, 동료의 대화 목록은 보이지 않습니다.
- 시스템 관리자와 관리자는 모든 대화를 볼 수 있습니다. 임원도 모든 대화를 볼 수 있지만 읽기만 되고 쓰지는 못합니다.
- "홈" 을 포함해 모든 대화가 사람별로 따로 열립니다. 다만 위 관리자·임원 열람은 홈 대화에도 그대로 적용되니, 사적인 내용은 사내 규정에 맞게 다룹니다.
- 이 범위는 관리자가 회사 정책에 맞춰 정합니다. 바꾸려면 관리자에게 요청합니다.
- 내가 올린 파일은 이 설정과 별개로 언제나 나와 관리자·임원만 볼 수 있습니다(4절).

## 6. 역할

| 역할 | 할 수 있는 것 |
| --- | --- |
| 직원 | 대화, 파일 첨부, 내 파일 다시 보기 |
| 중재자 | 직원 권한 + 승인 요청 처리. 대화는 직원과 같이 본인 것만 보입니다 |
| 임원 | 직원 권한 + 전체 대화 열람(읽기만) |
| 관리자 | 사용자 초대·역할 변경, 부서 관리, 모든 대화 열람, 감사 기록 조회 |
| 시스템 관리자 | 관리자 권한 + 시스템 설정 전체 |

관리자 권한이 필요한 설정 메뉴는 관리자에게만 표시됩니다.

## 7. 부서

- 사람은 부서에 속하고, 부서는 회사 자료에 닿는 범위의 단위입니다. 대화 공유 범위는 부서가 아니라 역할이 정합니다(5절).
- 지금은 공용 비서 하나로 운영하며, 부서별 전용 비서(부서 자료 폴더를 읽는 비서)는 회사 자료 폴더를 연결하는 시점에 켭니다.
- 부서별 비서를 켜면 그 부서 사람만 그 부서 폴더의 문서를 검색·요약할 수 있고, 다른 부서 폴더는 보이지 않습니다.

## 8. 관리자: 사용자 관리

- 왼쪽 아래 내 이름 메뉴 → "사용자 관리" 입니다.
- 초대: 이메일·역할·부서를 넣고 초대하면 초대 링크가 만들어집니다. 메일 발송이 설정되기 전에는 링크를 복사해 직접 전달합니다.
- 역할 변경·부서 변경·비활성화는 사용자 목록에서 합니다. 퇴사자는 비활성화하면 즉시 로그인이 막힙니다.
- 부서 추가·삭제는 "부서 관리" 에서 합니다.

## 9. 관리자: 감사 기록

- 내 이름 메뉴 → "감사 기록" 에서 누가 언제 로그인했고, 무엇을 물었고(제목 수준), 어떤 파일을 읽었고, 누가 사용자를 바꿨는지 볼 수 있습니다.
- 질문 본문은 기록하지 않습니다. 보관 기간은 90일입니다.
- 다른 부서 파일을 열려다 막힌 시도도 "접근 거부" 로 남습니다.

## 10. 관리자: 모델과 외부 메신저

- 답변 모델은 OpenAI(기본)와 Claude 두 가지가 준비돼 있습니다. 사용자는 대화마다 고를 수 있습니다.
- 텔레그램 봇을 붙여 메신저에서 질문할 수 있습니다. 다만 메신저 쪽은 로그인 계정과 연결되지 않으므로 허용된 사용자 목록으로만 통제되고, 감사 기록에는 남지 않습니다. 필요하면 별도로 요청합니다.

## 11. 자주 겪는 문제

| 증상 | 조치 |
| --- | --- |
| "모델을 사용할 수 없습니다" | 잠시 후 새로고침. 계속되면 관리자에게 알립니다(서버 업데이트 중일 수 있습니다) |
| 빨간 오류가 뜨고 답이 안 옴 | "새 세션" 으로 새 대화를 엽니다. 이전 대화에 걸린 작업 때문입니다 |
| 페이지가 "Error 1033" | 서버가 업데이트 중입니다. 5~10분 뒤 다시 엽니다 |
| 로그인이 안 됨 | 비밀번호 초기화 또는 관리자 확인(비활성 계정일 수 있음) |
| 다른 사람 파일이 안 열림 | 정상입니다. 파일은 올린 사람과 관리자만 봅니다 |

## 12. 지켜 주세요

- 개인정보나 계약상 비밀은 필요한 범위에서만 입력합니다. 입력 내용은 회사 서버에 보관되며 관리자가 감사 기록으로 볼 수 있습니다.
- 계정을 다른 사람과 공유하지 않습니다. 모든 기록은 계정 기준으로 남습니다.
- 공용 "홈" 대화에는 개인 질문을 쓰지 않습니다.
