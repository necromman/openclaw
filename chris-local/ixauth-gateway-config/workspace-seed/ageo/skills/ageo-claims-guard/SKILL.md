# 라포르몰 표시·광고 문안 게이트

라포르몰이 파는 베개와 마사지기는 **건강기능식품이 아니고, 의료기기 허가도 받지 않은 공산품**이다. 식품 기능성 문구 규칙은 적용되지 않고, 아래 여섯 가지가 적용된다. 회사·제품 사실은 `COMPANY.md` 에 있다.

| 근거 | 요지 |
| --- | --- |
| 의료기기법 제26조제7항 | 의료기기가 아닌 것에 의료기기와 비슷한 성능·효능이 있는 것으로 잘못 인식될 표시·광고 금지 |
| 표시광고법 제3조·제5조 | 거짓·과장·기만 광고 금지, 사실 주장은 사업자가 실증. 공정위 요청 시 15일 내 제출, 미제출이면 광고 중지 명령 |
| 추천보증 심사지침 | 후기·체험단·인플루언서의 대가 관계 표시 의무, 추천 내용의 입증책임은 광고주 |
| 전자상거래법 제21조의4 (시행 2026-07-21) | 후기 게시기간·등급평가·삭제 기준·이의제기 절차를 사전 공개 |
| 상품정보제공고시 (5) 침구류/커튼 | 품목별 필수 항목 표기, 인증 정보는 텍스트로 |
| 전안법 안전기준준수대상생활용품(가정용 섬유제품) | 라벨 7항목, 미표시 제품은 판매업자도 판매·진열 금지 |

**이 검사는 모델 판단에만 맡기지 않는다.** 아래 사전으로 문자열을 직접 훑고, 걸리면 무조건 보고한다. "문맥상 괜찮아 보인다" 로 통과시키지 않는다.

## 1. 언제 돌리나

- 상세페이지·FAQ·블로그 문안을 **새로 쓸 때**(출력 직전 자기 검사)
- 기존 페이지를 **감사할 때**(`aeo-page-audit` 5단계)
- JSON-LD 의 `description`·FAQ 답변을 채울 때
- 사용자가 문구를 주며 "이거 써도 되냐" 고 물을 때
- 후기·체험단 콘텐츠, 상품 추천 설문 화면을 볼 때

## 2. 왜 이것이 가장 위험한가

식약처는 2020년 6월 **공산품 베개 판매 온라인 사이트 1,635건을 점검해 의료기기 오인 광고 610건을 적발**했다. 유형은 거북목·일자목 교정 415건, 목디스크 완화 77건, 통증 완화 19건이다. 조치는 광고 시정 또는 접속 차단이고 판매자는 관할 지자체 조치를 받는다. 라포르몰 문안에서 가장 흔히 나오는 표현이 바로 적발 1순위 유형과 같다.

**"의료기기 아님" 을 함께 적어도 오인 광고 판단을 피하지 못한다.** 표현 자체를 빼는 것이 유일한 해결이다.

## 3. 금지 표현 사전

### (가) 질환·증상 교정·완화 (적발 1순위)

`거북목 교정`, `일자목 교정`, `목디스크 예방`, `목디스크 완화`, `척추측만증 개선`, `디스크 치료`, `경추 교정`, `자세 교정`(의료적 교정 의미), `체형 교정`, `견인 효과`, `지압 치료`, `재활`

### (나) 통증·증상 소멸

`통증 완화`, `통증 감소`, `목 통증이 사라진다`, `어깨 통증 해소`, `두통 완화`, `편두통 개선`, `근육 이완`(치료 어감), `염증 감소`

### (다) 생리 기능 개선

`혈액순환 개선`, `혈행 개선`, `신경 압박 해소`, `림프 순환`, `면역력 향상`, `자율신경 조절`, `뇌혈류 증가`

### (라) 수면·호흡 질환

`코골이 방지`, `코골이 개선`, `수면무호흡 개선`, `이갈이 방지`, `턱관절 장애 완화`, `불면증 치료`, `불면증 개선`

### (마) 의료 권위 차용

`의사 추천`, `의사가 쓰는`, `병원에서 쓰는`, `한의사 처방`, `임상 입증`(시험성적서 없이), `임상시험 결과`(출처 없이), `의료기기급`, `치료용`, `의료용`, 심의필 번호를 미허가 품목에 붙이는 것

### (바) 절대·과장

`100%`, `완벽`, `최고`, `유일`, `1등`(객관적 근거 없는 것), `즉효`, `기적`, `누구나 효과`, `무조건`, `부작용 없음`, `고객만족도 99%`(실증자료 없이), 근거 없는 후기 건수

### (사) 후기·체험단 과장

`쓰고 나서 목디스크가 나았어요`, `병원 안 가도 됩니다`, 효능을 단정하는 소비자 후기를 근거로 제시하는 것, 대가를 받은 후기에 대가 표시가 없는 것

### (아) 필수 표기 위반

KC 인증번호 임의 기재(성인용 베개는 KC 대상이 아니다), 인증·허가 정보를 이미지로만 게시, 상품정보제공고시 9항목 누락, 라벨 7항목 누락

**판정법**: 문장에서 질환·증상 명사(거북목, 목디스크, 통증, 두통, 코골이, 불면증, 척추측만증, 혈액순환)를 찾고 그 뒤에 효과 동사(교정, 완화, 개선, 해소, 예방, 치료, 방지)가 붙으면 위반이다. 명사와 동사가 문장을 건너 붙어 있어도 같다.

## 4. 허용 표현

**물리 사양과 사용 경험을 그대로 적는다.** 효능 수치 대신 사양 수치를 쓴다.

- 머리와 목을 받쳐 편안한 수면 자세를 돕는다
- 머리와 목을 안정적으로 지지한다
- 체압을 분산한다
- 정자세 기준 높이 7cm, 옆으로 누울 때 10cm
- 메모리폼 밀도 50D, 경도 2종(레귤러 소프트·엑스트라 소프트) 선택 가능
- 뒤척임이 적은 구조, 통기성 커버, 세탁 가능한 커버
- 14일 무료 경도 교환
- 하루 10분 사용 예시, 사용 부위와 방법 안내

| 금지 문안 | 허용 문안 |
| --- | --- |
| 거북목을 교정합니다 | 목의 곡선에 맞춰 머리와 목을 받쳐 줍니다 |
| 목디스크 통증을 완화합니다 | 누운 자세에서 목에 실리는 압력을 분산합니다 |
| 혈액순환을 개선합니다 | 눌리는 부위가 적어 오래 누워도 편안합니다 |
| 코골이를 방지합니다 | 옆으로 누울 때 높이 10cm 로 머리를 받쳐 줍니다 |
| 자세를 바르게 교정합니다 | 편안한 수면 자세를 유지하도록 돕습니다 |
| 임상으로 입증된 효과 | 자사 시험 결과(시험기관·항목·일자 병기), 근거 없으면 삭제 |
| 고객만족도 99% | 구매자 후기 648건(집계 기준·기간 병기), 근거 없으면 삭제 |

치환 규칙 하나로 요약된다. **"교정·완화·치료·예방" 은 "지지·받침·높이 유지·체압 분산" 으로, 효능 수치는 물리 사양 수치로 바꾼다.**

## 5. 필수 표기 체크

### 상품정보제공고시 (5) 침구류/커튼 9항목

품질(섬유 조성·혼용률, 메모리폼은 충전재 병기), 치수, 제조자, 제조국, 세탁방법, 기능성 인증 여부, 제조연월 또는 제조번호, A/S 책임자, 연락처.

- 품목별 정보는 **상품 소개보다 앞에** 두기를 고시가 권장한다.
- 인증·허가 정보는 **문자로** 명확히 표시한다. "제품에 별도 표기" 나 사진 게시로 대체할 수 없다. 상세페이지 텍스트화가 AEO 과제이면서 동시에 고시 준수 과제인 이유가 이것이다.
- **KC 인증번호를 임의로 적지 않는다.** 성인용 베개는 KC 대상이 아니다. 만 13세 이하 어린이용 베개만 어린이제품 안전특별법으로 KC 대상이 되고, 그때는 고시 유형도 "(23) 어린이제품" 을 쓴다.

### 전안법 라벨 7항목

섬유 조성·혼용률(충전재 병기), 제조자 또는 수입자명, 제조국명, 제조연월 또는 로트번호, 치수(권장), 취급상 주의사항, 표시자 주소·전화번호. 한글로, 세탁에도 지워지지 않는 방법으로 부착한다. 미표시 제품은 판매업자도 판매·진열·보관이 금지되고 각 500만원 이하 과태료다.

### 후기 운영 (전자상거래법 제21조의4, 시행 2026-07-21)

게시기간, 등급평가 기준, 삭제 기준, 삭제 시 이의제기 절차를 사전 공개해야 한다. 위반은 1천만원 이하 과태료다. 부정적 후기를 임의로 숨기거나 지우는 운영은 명문 위반이다. 라포르몰 후기 648건 운영 정책을 공개 페이지로 만들도록 제안한다.

### 대가 표시 (추천보증 심사지침)

- 표시 위치는 **제목 또는 본문 첫 부분**이고 본문과 구분되게 한글로 적는다. 더보기란·댓글·해시태그 뭉치 속 표시는 미표시와 같게 취급된다. 2024년 공정위 모니터링에서 위반 유형 1위가 부적절한 위치 39.4%였다.
- `체험단`, `AD`, `Sponsor` 단독 표기는 부적절하다. 어떤 대가를 받았는지 쓴다.
- 지침 연혁은 2020-09-01, **2024-12-01**(문자 매체 공개방식, 조건부·미래 대가 포함), **2026-06-01**(AI 생성 가상인물 명시) 개정이다.
- 체험단이 "목 통증이 사라졌다" 고 쓰면 실증책임은 진바이오테크에 있고, 같은 문장이 의료기기 오인 광고로도 평가된다. **후기 효능 주장은 이중 위험이다.**

## 6. 검사 절차

1. 대상 문자열을 모은다(본문, 헤딩, FAQ, alt, 메타 설명, JSON-LD 값, 이미지 속 글자를 옮긴 텍스트, 옵션명, 배너 문구, 상품 추천 설문의 선택지).
2. 3절 사전의 (가)~(아) 를 순서대로 훑는다. 부분 일치도 잡는다.
3. 걸린 것마다 위치·원문·유형을 적는다.
4. 유형별로 대체안을 만든다. 대체안도 다시 1~3 을 통과시킨다.
5. 5절 필수 표기 체크를 별도 표로 낸다. 누락은 위반과 같은 줄에 두지 않고 따로 적는다.
6. 실증이 필요한 수치(만족도, 후기 수, 시험 결과)는 **"실증자료 확인 필요"** 를 붙인다.

## 7. 출력 형식

위반이 있으면 다른 어떤 결과보다 위에 놓는다.

```markdown
## 규제 경고 - <N>건

| 위치 | 원문 | 유형 | 근거 | 대체안 |
| --- | --- | --- | --- | --- |
| 상세 3번째 이미지 카피 | 거북목을 교정해 줍니다 | (가) 질환 교정 | 의료기기법 제26조제7항 | 목의 곡선에 맞춰 머리와 목을 받쳐 줍니다 |
| 상품 추천받기 3단계 | 고민: 목디스크 | (가) 질환 교정 | 의료기기법 제26조제7항 | 선택지를 수면 자세·체형·사용 부위로 바꾼다 |
| 상단 배너 | 고객만족도 99% | (바) 절대·과장 | 표시광고법 제5조 | 구매자 후기 648건(2026-09 기준), 실증자료 확인 필요 |

## 필수 표기 누락
| 항목 | 현재 | 근거 |
| --- | --- | --- |
| 세탁방법 | 이미지에만 있음 | 상품정보제공고시 (5), 인증·정보는 텍스트 표기 |

> 이 목록은 표시·광고 규정 위반 가능성이 있는 표현을 사전으로 걸러 낸 것이고, 적법성을 보증하지 않는다. 의료기기 오인 광고 판단과 실증자료 충분성은 최종적으로 담당자와 법률 검토의 몫이다.
```

위반이 없으면 한 줄로 적는다.

```markdown
## 규제 경고
발견된 금지 표현 없음. (사전 (가)~(아) 검사, 대상 문자열 <N>개)
```

## 8. 사용자가 금지 문구를 요구할 때

거절하되 이유와 대안을 같이 준다.

1. 왜 쓸 수 없는지 한 줄(어느 유형, 어느 법 조항인지).
2. 같은 목적을 달성하는 허용 문안을 실제로 써 준다.
3. 그래도 그 소구가 필요하면 무엇이 있어야 하는지(의료기기 허가·신고, 자율심의 결과, 시험성적서, 실증자료).

"담당자가 심의를 받으면 됩니다" 로 끝내지 않는다.

## 9. 메디월드몰과의 차이

의료기기법 제26조제7항은 "누구든지" 로 규정해 광고 대상이 전문가인지 일반인인지를 구분하지 않는다. 폐쇄 공간이고 독자가 의료인이라는 점 때문에 오인 판단이 실무상 완화될 여지는 **판례 미확인 추정**이며, **메디월드몰 문안을 라포르몰로 복사해 오는 것은 금지다.**
