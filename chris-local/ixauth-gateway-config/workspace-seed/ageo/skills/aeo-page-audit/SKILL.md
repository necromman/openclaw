# 상세페이지 AEO/GEO 감사

검색 답변엔진(네이버 AI 브리핑·AI 탭, ChatGPT, Gemini/AI Overviews, Perplexity)이 이 페이지를 **인용할 수 있는가**를 센다. 순위가 아니라 인용이 목표다.

## 0. 시작 전에

1. `web_fetch` 로 HTML 을 받는다. 본문 텍스트가 500자 미만이면 스크립트로 그리는 페이지이므로 `browser` 로 다시 연다.
2. 받은 HTML 을 그대로 세지 말고, 화면에 실제로 보이는 텍스트를 기준으로 센다. 한국식 통이미지 상세페이지는 HTML 텍스트가 거의 없는 것이 정상이며, 그것이 이 감사의 1번 발견 사항이다.
3. 크롤러 접근은 `aeo-crawler-access`, 스키마는 `aeo-schema-jsonld`, 문안 규제는 `ageo-claims-guard` 에서 따로 센다. 이 스킬은 본문 구조를 센다.
4. 기본 대상은 라포르몰 상품 상세다. 회사·상품·플랫폼 사실과 2026-09-14 실측 기준선은 `COMPANY.md`, 보고의 기준 예시는 `PLAYBOOK.md` 에 있다.

## 1. 체크리스트 (10항목)

각 항목은 통과/부분/미달 셋 중 하나로 판정한다. 판정 근거로 실제 숫자를 적는다.

### (1) 직답 블록 - 12점
각 섹션 첫 문단이 **40~60단어**로 그 섹션의 질문에 바로 답하는가. 생성엔진은 이 덩어리를 통째로 인용한다.
- 통과: 주요 섹션 전부에 있다
- 부분: 일부에만 있다
- 미달: 도입부가 홍보 문구로 시작한다

### (2) 질문형 H2 - 10점
헤딩이 사용자가 실제로 검색하는 질문 형태인가. "제품 특징" 대신 "베개 높이는 몇 cm 가 맞나" 처럼 쓴다.
- 세는 법: `h2`·`h3` 를 뽑아 질문형 개수 / 전체 개수

### (3) 표 - 12점
제품 스펙이 HTML `table` 인가. 다음 아홉 줄이 있으면 만점이다: 품명·모델명, 소재(섬유 조성·혼용률과 충전재), 크기(가로x세로x높이 cm), 높이(정자세·측면), 경도 또는 밀도, 세탁방법, 제조자·제조국, 커버 분리·교체 가능 여부, A/S 책임자·연락처.
- 이 아홉 줄은 상품정보제공고시 "(5) 침구류/커튼" 필수 표기와 거의 겹친다. 규제 준수와 AEO 가 같은 작업이 되는 지점이다.
- 이미지 속 표는 0점으로 센다. 엔진이 읽지 못한다.

### (4) FAQ - 12점
질문 **6~12개**가 HTML 텍스트로 있는가. 실제 CS 문의(내 키·체형에 맞는 높이, 새 베개 적응 기간, 커버 세탁 방법, 경도 교환 절차, 옆으로 누워 자도 되는지, 사용 부위와 시간)를 그대로 쓰는 것이 가장 좋다.
- 쿠폰·적립금 FAQ 는 제품 FAQ 로 세지 않는다. 라포르몰의 기존 FAQ 6건이 전부 그쪽이다.
- 6개 미만은 부분, 0개는 미달. 13개 이상은 감점하지 않되 중복 질문을 지적한다.

### (5) 텍스트/이미지 비율 - 12점
화면에 보이는 본문 텍스트 글자 수 대비 이미지 개수. 통이미지 상세페이지의 핵심 문제다.
- 세는 법: 본문 글자 수 / 상세영역 이미지 개수
- 통과 기준: 이미지 1장당 본문 텍스트 200자 이상
- 개선안은 언제나 같다: **이미지 속 핵심 카피를 실제 HTML 텍스트로 이중 게재한다.** 디자인은 그대로 두고 같은 문장을 텍스트로 한 번 더 넣는 것이다.

### (6) alt 속성 - 8점
이미지에 사실을 서술하는 alt 가 있는가.
- 통과: 주요 이미지 전부에 사실 서술 alt
- 미달: 비었거나 `image1.jpg` 이거나 키워드를 나열했다. **키워드 나열 alt 는 스팸으로 취급되므로 없느니만 못하다**고 적는다.

### (7) 최신성 메타 - 10점
`datePublished`·`dateModified` 가 있고 최근인가. 생성엔진은 분기 단위로 갱신되는 문서를 선호한다.
- 통과: 두 값이 있고 dateModified 가 6개월 이내
- 부분: 하나만 있다
- 미달: 없다

### (8) 엔티티 일관성 - 8점
브랜드명·제품명·소재명 표기가 페이지 안에서, 그리고 다른 채널(자사몰·SNS·보도자료)과 같은가. 인용되는 문서는 엔티티 밀도가 높다(실측 20.6% 대 일반 7%).
- 세는 법: 같은 대상의 표기 변형 개수를 적는다. 예: "라포르" / "Rapport" / "CST" / "씨에스티" 혼용

### (9) 인증·근거 명시 - 8점
시험성적서(시험기관·항목·일자), 특허·디자인 등록번호, 소재 규격, 제조자·제조국이 텍스트로 있는가. 구체 수치와 1차 출처는 GEO 논문에서 가시성을 30~40% 올린 요소다.
- **KC 인증번호를 적지 않는다.** 성인용 베개는 KC 대상이 아니므로 임의 기재가 그대로 위반이다(`ageo-claims-guard` 5절).
- 의료기기 광고 심의필 번호를 미허가 품목에 붙인 경우는 가점 대상이 아니라 규제 위반으로 보고한다.

### (10) 네이버 5원칙 - 8점
네이버가 2026-05 에 공개한 콘텐츠 5원칙에 비추어 본다: 직접 경험, 일관된 주제, 거짓 없는 진정성, 읽기 쉬운 구조, 최신성. 기계 생성 글·출처 불명 짜깁기·과도한 홍보는 인용에서 빠진다.
- 항목마다 1.6점, 다섯 개 합산

## 2. 보고서 형식

`SOUL.md` 의 기준 답변 형식으로 낸다. 덩어리 순서는 **측정한 것 -> 왜 이게 치명적인가 -> 우선순위별 처방 -> 한 가지 더** 이고, 칸 전체는 `AGENTS.md` 5절에 있다. 깊이의 기준은 `PLAYBOOK.md` 의 라포르몰 감사 예시다. **점수는 기본 산출물이 아니다.** 요청받았을 때나 재감사 대조에만 부록 산식으로 계산해 붙인다.

이 스킬이 채우는 곳은 두 군데다.

**(1) "측정한 것".** 1절 체크리스트 열 항목을 서술이 아니라 숫자로 적는다. 줄마다 통과인지 실패인지 드러나게 쓴다.

```text
측정한 것

- robots.txt는 Allow: / 로 봇 차단 없음. 이건 통과다
- JSON-LD 구조화 데이터 0개. Product·Offer·FAQ 스키마가 전무하다
- H1 태그 없음. H2는 "장바구니 담기"(팝업 UI 문구)
- title이 전 페이지 동일하다. meta description도 한 줄 동일
- 제품 상세 텍스트 1,877자인데 대부분이 배송비·교환환불 안내다. 제품 설명은 이미지 48장 안에 있다
- HTML table 0개. 스펙 아홉 줄 전부 이미지 속
- 제품 FAQ 0건(기존 FAQ 6건은 전부 쿠폰·적립금)
- dateModified 없음, 엔티티 표기 변형 3종
- html lang 없음, img alt 누락 6개, llms.txt 404
```

**(2) "우선순위별 처방".** 3절 순서로 1순위부터 5순위까지 쓴다. 각 순위에 무엇을·어떻게·왜를 적고, 고도몰5 에서 실제로 고치는 화면·스킨 파일·치환코드를 지목한다. 기여도 비율을 아는 항목은 그대로 쓴다("이게 80%다"). 4순위 질문형 페이지의 작성 규칙은 `AGENTS.md` 2-1 절이 정본이다.

**진단으로 끝내지 않는다.** 측정 목록만 있고 처방이 없으면 그 보고서는 미완이다.

## 3. 우선순위 정하는 법

**0순위는 규제 위반 시정이다**(`ageo-claims-guard`). 그다음은 효과 대비 품이 적은 것이 먼저다. 순서는 대체로 이렇다. 라포르몰 전체의 우선 작업 10개는 `AGENTS.md` 4절에 있고, 다섯 순위로 줄인 처방 순서와 GEO 를 후순위로 두는 이유는 `AGENTS.md` 2절에 있다.

1. 크롤러 차단 해제 (막혀 있으면 다른 모든 것이 무효)
2. 이미지 카피의 HTML 텍스트 이중 게재
3. 제품 스펙 HTML 표
4. FAQ 6~12문항 + FAQPage 스키마(구글 리치결과는 2026-05-07 종료됐지만 타입은 유효하고 인용에는 도움이 된다)
5. 섹션별 40~60단어 직답 블록
6. Product 스키마 보강
7. 질문형 헤딩으로 교체
8. alt 사실 서술로 교체
9. 비교 페이지 신설 (비교형 질의는 Top10 중첩률 100%, 리트리벌당 인용 1.87회로 가장 높다)
10. 리뷰·UGC 확보

## 4. 알아 둘 것

- 네이버 AI 브리핑 인용 실측 272건의 출처 분포는 블로그 158, 웹사이트 45, 네이버 DB 44, 카페 19, 지식iN 6 이다. **자사 웹사이트만 고쳐서는 절반도 못 먹는다**는 뜻이므로, 블로그 운영을 함께 제안한다.
- Top10 밖에서 인용되는 비율이 49.3% 다. 검색 순위가 낮아도 인용될 수 있다.
- 질의 유형별로 다르다. 정의형은 Top10 중첩률 28.6%(순위 밖 인용이 흔함), 비교형·상업형은 100%(순위가 곧 인용). 베개는 **정보 의도 질의**("경추 베개 효과", "메모리폼 베개 고르는 법", "베개 높이 몇 cm")를 노린다. "거북목 베개 추천" 같은 구매 의도 질의에서는 AI 브리핑이 뜨지 않고 광고·가격비교가 자리를 차지한다(2026-09-14 관찰).
- 키워드 반복은 효과가 없거나 역효과다(GEO 논문 arXiv 2311.09735). 통계·인용문·출처 명시가 효과가 있다.

## 부록. 점수 산식과 등급

점수는 기본 산출물이 아니다. 사용자가 점수를 요청했을 때, 또는 재감사에서 이전 보고서와 대조할 때만 계산해 붙임으로 낸다. 기본 산출물은 2절의 기준 형식이다.

- 항목 배점 합계 100점. 통과 = 배점 전부, 부분 = 배점의 절반, 미달 = 0점.
- 계산 과정을 보고서에 남긴다. 예: `직답 12 + 질문형 H2 5(부분) + 표 0 + ... = 58`
- 감점 규칙 하나: `ageo-claims-guard` 에서 금지 표현이 하나라도 나오면 총점 옆에 **"규제 위반 있음"** 을 붙인다. 점수를 깎지는 않는다. 두 문제는 성질이 다르고, 규제는 점수보다 위에 있다.

### 등급 (점수를 계산했을 때만 쓴다)

| 점수 | 등급 | 뜻 |
| --- | --- | --- |
| 80~100 | A | 인용 후보. 갱신 주기만 지키면 된다 |
| 60~79 | B | 구조는 있으나 빠진 조각이 있다 |
| 40~59 | C | 사람은 읽을 수 있으나 엔진은 읽지 못한다 |
| 0~39 | D | 통이미지 상태. 텍스트 이중 게재부터 시작한다 |
