# PLAYBOOK.md - 답변의 기준 예시

이 파일은 "이 정도로 답해야 한다" 를 보여 주는 견본이다. 아래는 라포르몰(`www.cstpillow.com`) 감사 한 건의 완성된 답변이고, 형식 규정은 `SOUL.md` 의 기준 답변 형식, 채우는 칸은 `AGENTS.md` 5절에 있다.

**새 감사 요청이 오면 이 예시의 형식과 깊이를 기준으로 답한다.** 덩어리 순서(첫 문장 -> 측정한 것 -> 왜 치명적인가 -> 우선순위별 처방 -> 한 가지 더)를 바꾸지 않고, 숫자의 밀도와 문장의 길이도 이 수준으로 맞춘다. 처방이 없으면 그 답은 미완이다.

## 라포르몰 감사 예시

```text
cstpillow.com 실제로 긁어서 봤다. 결론부터: 지금 상태로는 AI가 이 사이트를 인용하고 싶어도 인용할 문장이 하나도 없다. 차단 문제가 아니라 읽을 텍스트가 없는 문제다.

측정한 것

- robots.txt는 Allow: / 로 봇 차단 없음. 이건 통과다
- JSON-LD 구조화 데이터 0개. Product·Offer·FAQ 스키마가 전무하다
- H1 태그 없음. H2는 "장바구니 담기"(팝업 UI 문구)
- title이 전 페이지 동일하다. 메인도 CST 스탠다드 상세페이지도 똑같이 "우리집 마사지 전문가, 라포르". meta description도 전 페이지 한 줄 동일
- 제품 상세페이지 텍스트가 1,877자인데 그중 대부분이 배송비·교환환불 안내다. 실제 제품 설명은 이미지 48장 안에 들어 있다
- sitemap.xml이 2020년 5월 생성본이고 http:// 주소에 login.php까지 들어 있다
- html 에 lang 속성 없음, img 6개 alt 누락, og:title("라포르몰")과 title 불일치, llms.txt 404

왜 이게 치명적이냐면
누가 챗봇에 "목 마사지기 추천"이라고 물으면 모델은 웹에서 문장을 찾아 인용한다. 이 사이트에서 건질 수 있는 문장은 "뭉친 목, 어께 하루 10분으로" 정도가 전부다. 참고로 그 문구, '어깨'가 '어께'로 오타다. 경쟁사가 "경추 마사지기는 몇 분 사용이 적당한가"에 200자짜리 답을 텍스트로 써놨으면 그쪽이 인용된다. 이미지는 아무리 잘 만들어도 인용 대상이 아니다.

우선순위별 처방

1순위. 상세페이지 이미지의 텍스트를 HTML로 복제 (이게 80%다)
이미지는 그대로 두고, 그 아래에 같은 내용을 텍스트로 다시 깐다. 재질·크기·무게·전압·소음도·세척법·사용 시간·주의사항. 특히 숫자를 박아라. 모델은 "편안합니다"는 버리고 "높이 10cm, 무게 1.2kg, 1회 10분 권장"은 인용한다.

2순위. 페이지별 title·description 분리
"CST 스탠다드 마사지기 - 목·어깨 속근육 지압 | 라포르" 처럼 제품마다 다르게. 지금은 194개 페이지가 한 개 제목을 공유한다.

3순위. Product 스키마 삽입
제품 상세에 JSON-LD로 name·brand·price·priceCurrency·availability·aggregateRating을 넣는다. 고도몰이면 스킨 템플릿 한 군데만 고치면 194페이지에 다 붙는다.

4순위. 질문형 페이지 신설
이게 AEO의 본체다. 제품 페이지가 아니라 질문 페이지로 인용을 받는다.
- "경추베개는 높이를 몇 cm로 해야 하나"
- "목 마사지기는 하루 몇 분이 적당한가"
- "라텍스 베개와 메모리폼 베개 차이"
- "마사지기를 쓰면 안 되는 경우는"
각 페이지 규칙은 제목을 질문 그대로 쓰고, 첫 두 문장에 결론을 완결된 문장으로 박고, 그 뒤에 근거를 쓰는 것. 그리고 답 끝에 자사 제품을 한 줄 연결한다. 모델은 첫 문단을 통째로 떠간다.

5순위. 위생
sitemap 재생성(https, 로그인 페이지 제외), html lang="ko", img alt 채우기, 오타 수정.

한 가지 더
이 사이트는 특허·인증 메뉴가 있다. 인증번호와 시험 결과를 텍스트로 써두면 AI가 근거로 잡기 아주 좋은 재료다. 지금은 그것도 이미지일 가능성이 높다.
```

## 이 예시를 그대로 쓸 때의 규제 주의

위 예시는 형식과 깊이의 기준이므로 문장을 고치지 않고 그대로 둔다. 다만 예시 안의 문안을 실제 페이지에 올릴 때는 `ageo-claims-guard` 를 먼저 통과시킨다. 세 군데를 본다. 첫째, 2순위의 title 예시에 있는 "속근육 지압" 은 `지압 치료` 처럼 치료 어감이 붙지 않아 사전에 걸리지는 않지만, 실제 게시 전에 검사 한 번을 거친다. 둘째, 4순위의 "마사지기를 쓰면 안 되는 경우는" 페이지는 답을 쓰는 순간 질환명이 나열되기 쉽고 그것이 의료기기 오인 광고로 평가된다. 물리 사양과 사용 안내 수준으로만 쓰고 질환 판단은 담당자와 전문가에게 넘긴다. 셋째, 1순위에서 옮겨 적는 숫자(무게·소음도·사용 시간)는 자사 측정값이나 시험성적서에 근거가 있어야 하고 근거가 없으면 적지 않는다. 규제는 점수보다 위에 있고 처방보다도 먼저 보고한다.
