## 5. 경쟁·인용 환경 요약 (2026-09-14)

- **네이버**: "거북목 베개 추천" 같은 구매 의도 질의에는 AI 브리핑이 뜨지 않고 광고·가격비교·UGC 가 차지한다. "경추 베개 효과"·"메모리폼 베개 고르는 법" 같은 정보 의도 질의에서만 AI 브리핑이 뜬다. 인용의 70~82%가 네이버 내부 UGC(블로그·카페)이고 272건 표본에서 49.3%가 검색 Top10 밖이었다. **네이버 블로그 자산이 없는 현 상태로는 AI 브리핑 인용이 사실상 불가능하다.**
- **해외 엔진**: 네이버 생태계(스마트스토어·블로그·카페·쇼핑)가 GPTBot·OAI-SearchBot·ClaudeBot·Claude-SearchBot·PerplexityBot 을 전면 차단한다. 즉 ChatGPT·Claude 가 한국 경추베개를 추천할 때 스마트스토어와 네이버 블로그를 원천적으로 못 본다. 자사몰이 열려 있는 것이 그대로 기회다.
- **경쟁 브랜드**: 가누다(고도몰, GPTBot·ClaudeBot 차단), 지누스(고도몰, 일부 차단), 삼분의일(별도 도메인 blog.3boon1.com 롱폼 비교 콘텐츠, AI 봇 전면 허용, 콘텐츠 자산 최강), 템퍼 코리아(전면 허용). 그 밖에 슬립퍼·코자미아·슬라운드·헬렌스타인·프로젝트슬립·바디씨·베네폼.
- **포맷**: ChatGPT 인용은 비교 콘텐츠가 95%, Perplexity 는 상품 리스팅 84%. 인용의 44.2%가 도입부에서 추출되고 인용 페이지 53.4%가 1,000단어 미만이다. GEO 논문(arXiv 2311.09735, KDD 2024)에서 인용문 추가 27.8%·통계 추가 25.9%·문장 유창성 25.1%·출처 명시 24.9% 개선, **키워드 반복은 무효 또는 역효과**.
- **스키마 정책**: FAQPage 리치결과는 2026-05-07 구글에서 종료(타입 자체는 유효). HowTo 는 2023년 폐기. 유효한 커머스 타입은 Product+Offer, AggregateRating/Review, BreadcrumbList, Organization, VideoObject. 구글은 "AI 노출 전용 스키마는 없다" 면서도 **"중요한 콘텐츠는 텍스트로 두라"** 를 명시한다. 라포르몰 통이미지 상세가 정확히 여기에 걸린다.

- 섬유 커버 없이 폴리우레탄폼이 노출된 베개의 전안법 부속서 적용(**추정**)
- 공정위가 기능성 베개 광고를 직접 제재한 사건, 한국소비자원의 기능성 베개 비교시험 보고서(존재 미확인)
- 2025~2026년 국내 기능성 베개 시장 규모·점유율

## 용어 설명

- **고도몰5** - NHN커머스의 쇼핑몰 솔루션. 임대형은 스킨 HTML 은 고칠 수 있으나 서버 설정은 건드릴 수 없다.
- **스킨** - 쇼핑몰 화면 템플릿 묶음. `goods_view.htm` 같은 파일 단위로 편집한다.
- **치환코드** - 스킨 안에서 `{=goodsView['goodsPrice']}` 처럼 쓰면 실제 상품 데이터로 바뀌는 변수. 전 상품에 자동 적용되는 코드를 심을 때 쓴다.
- **통이미지 상세페이지** - 설명을 전부 이미지로 만들어 올린 형태. 사람은 읽지만 검색엔진과 AI 는 글자를 못 읽는다.
- **canonical(대표 URL)** - 같은 내용이 여러 주소로 열릴 때 "이것이 정본" 이라고 알리는 태그.
- **JSON-LD** - 페이지 안에 기계가 읽는 구조화 데이터를 JSON 으로 심는 방식.
- **UGC** - 이용자가 만든 콘텐츠. 네이버 블로그·카페 글 등.
- **AI 브리핑** - 2025-03 도입된 네이버 통합검색 최상단의 AI 요약 답변 블록.
- **응답 크롤러 / 학습 크롤러** - 앞은 AI 가 답할 때 페이지를 가져오는 봇(OAI-SearchBot 등), 뒤는 모델 학습용 봇(GPTBot 등). 앞을 막으면 인용 자격이 사라진다.
- **CST(두개천골요법)** - 머리뼈와 꼬리뼈의 미세한 움직임을 다루는 수기 요법. 이 회사 브랜딩의 근거로 쓰인다.
- **공산품** - 의료기기 허가를 받지 않은 일반 생활용품. 의료적 효능을 표방할 수 없다.
