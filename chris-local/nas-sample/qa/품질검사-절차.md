# 완제품 품질검사 절차 (샘플)

> 실제 절차서가 아니다. 마운트 확인용으로 지어낸 가짜 문서다.\
> 문서번호 QA-SOP-014, 개정 3판, 시행 2026-05-01. 작성 김샘플, 승인 박가상.

## 1. 적용 범위

사료첨가용 생균제 완제품(분말)의 출고 전 검사에 적용한다.\
원료 입고 검사와 공정 중 검사는 각각 QA-SOP-011, QA-SOP-012 를 따른다.

## 2. 검사 항목과 기준

| 항목     | 방법         | 기준             | 주기     |
| -------- | ------------ | ---------------- | -------- |
| 성상     | 육안         | 담황색 균일 분말 | 배치마다 |
| 수분     | 건조감량     | 6.0% 이하        | 배치마다 |
| 생균수   | 평판배양     | 표시량 이상      | 배치마다 |
| pH       | 현탁 후 측정 | 4.0 ~ 6.5        | 배치마다 |
| 대장균군 | 선택배지     | 음성             | 배치마다 |
| 살모넬라 | 증균 후 확인 | 음성             | 월 1회   |
| 중금속   | 외부 의뢰    | 기준 이내        | 분기 1회 |

## 3. 시료 채취

1. 배치당 3개 지점(상·중·하)에서 각 50 g 을 채취해 합친다.
2. 채취 용기에 배치번호·채취일시·채취자를 적는다.
3. 검사용과 보관용으로 나누고, 보관용은 유효기한 후 6개월까지 보관한다.

## 4. 부적합 처리

1. 1개 항목이라도 기준을 벗어나면 그 배치를 **보류** 상태로 표시하고 출고를 막는다.
2. 재검은 같은 보관 시료로 2회 실시한다. 2회 모두 적합이면 원인 조사 후 판정한다.
3. 재검에서도 부적합이면 부적합 보고서를 쓰고 폐기 또는 재작업을 결정한다.
4. 모든 판정은 품질보증 책임자가 승인한다. 생산 부서 단독으로 뒤집을 수 없다.

## 5. 기록

- 검사 성적서는 배치번호로 보관하며 보존기간은 5년이다.
- 이 폴더의 문서를 고칠 때는 개정 이력을 남긴다. 개정 없이 내용만 바꾸면 안 된다.
