## 3-1. NAS 설치·폴더 권한 대응 (2026-09-07 추가)

사용자 지시: 사용자·그룹별 폴더 접근 권한은 `chris-local/infra/local/openclaw-jinbio-nas-feasibility.md`(정본 chris-server) 의 결론대로 하고, 진바이오테크 NAS(Synology DS218+) 설치에 대응한다. 인프라 사본과 접속 절차는 [infra/README.md](infra/README.md).

채택 (문서의 "경로 A"):

- 부서·사람 = 에이전트 1개. 에이전트 워크스페이스 = 허용 폴더(NAS 공유를 호스트에 SMB/NFS 마운트). **화이트리스트 = 워크스페이스에 넣은 폴더, 안 넣으면 차단.** 블랙리스트는 채택하지 않는다.
- 파일 서버 용도 에이전트는 `readonly` 프로필 + `tools.fs.workspaceOnly: true` + 셸 exec 계열 도구 끔(G 단계).
- NAS 권한과의 자동 동기화는 없다. NAS 로컬 사용자 20명은 IX-Auth CSV 벌크로 1회 투입하고 부서(공유 폴더) 그룹에 수동 배치한다.
- 호스트는 별도 x86 미니PC·VM 을 권장하고 NAS 직접 설치는 PoC 로 한정한다(2코어 Celeron, RAM 10GB).
- 사내망 배치는 `gateway.bind: lan` + `publicOrigin: http://<NAS IP>:18800` 으로 도메인 없이 동작. 평문 HTTP 는 세션 탈취 위험이라 IP SAN 사설 인증서 리버스 프록시를 권장.

### J 단계 - 관리자 화면 마감·결함 수정 (2026-09-08 추가)

브랜치 `chris/delivery-j`. 사용자 피드백(2026-09-08 오전) 반영.

1. **관리자 WS 권한 결함**: ix-auth 로그인 연결에서 `applyConnectionScopeCap` 이 브라우저 선언 `x-openclaw-scopes` 교집합으로 잘라 시스템 관리자도 `operator.admin` 을 못 받는다(시크릿 모드·계정 선택 등 비활성). ix-auth 세션은 역할 정의 스코프를 상한으로 그대로 쓰도록 수정, 테스트.
2. 사용자 표·감사 표 **full width**(포크 규칙).
3. **IX-Auth 콘솔 SSO**: 시스템 관리자가 `/admin/identity/` 로 들어가면 재로그인 없이 진입. 게이트웨이[<sup>1</sup>](#g1)가 IX-Auth 신원 교환으로 같은 사람의 콘솔 토큰[<sup>2</sup>](#g2)을 발급해 심는다. admin 이하는 기존대로 링크 미노출·중계 차단.
4. **부서·에이전트·접근 폴더 관리 화면** `/settings/departments`: 부서(그룹 `dept-*`) 목록·생성·이름·구성원, 부서별 에이전트 바인딩, 에이전트별 허용 폴더(마운트된 NAS 루트 아래 선택, 화이트리스트)·읽기 전용 여부·색인 폴더. 저장 시 게이트웨이 config 패치(`agents.entries`, `memory.search.extraPaths`) + `department_agents` 바인딩. superadmin 만.
5. 테스트 시드 정리 명령·문서: 깨진 세션(`Unassigned user own note` 등)·테스트 계정 삭제, 납품 전 초기화 절차(DEPLOY.md).
6. 감사 화면 다듬기: 역할 한국어 라벨, 설정 사이드바 항목 노출. 사용자 표의 부서를 이름으로.

### K 단계 - J 잔여 마감 (2026-09-08 추가)

브랜치 `chris/delivery-k`. J 단계가 남긴 항목과, 감독의 18800 실측(J 이미지, admin 계정)에서 나온 결함 3건.

1. **부서 삭제** `/settings/departments`: 시스템 관리자 전용, 빈 부서만. 신원 서버 그룹과 포크 투영을 함께 치우고 풀려난 에이전트의 워크스페이스·색인 폴더를 회수한다. 절차는 [AUTH-DEPARTMENTS.md](AUTH-DEPARTMENTS.md) 9.3-1.
2. **부서 이름 변경**: 벤더에 그룹 이름 변경 API 가 없어 게이트웨이 표시 이름만 바꾸는 것을 유지하고, 그 이름을 읽는 화면을 통일한다(감사 표만 코드를 그대로 찍고 있었다).
3. **콘솔 로그아웃 404**: 콘솔의 로그아웃이 막아 둔 자기 로그인 폼으로 이어지던 것을 "게이트웨이로 돌아가기" 로 바꾼다. 세션이 유지되므로 재로그인 없이 다시 들어온다. [AUTH-IXAUTH.md](AUTH-IXAUTH.md) 7.2.
4. **사용자 표 다듬기**: 역할 미부여 계정의 빈칸을 "미지정" 으로, 역할 필터에 중재자 추가, 주소·부서 칸 폭 상한과 말줄임, 빈 목록 문구를 행 전체 블록으로, 좁은 폭 여백.
5. **xlsx 날짜 서식**: 색인 변환에서 날짜 셀이 일련번호로 남던 것을 셀 서식을 읽어 `YYYY-MM-DD`(시각이 있으면 `YYYY-MM-DD HH:mm`)로. [KNOWLEDGE.md](KNOWLEDGE.md) 5절.
6. **시작 번들 예산 기준선**: `pnpm check` 가 이 검사를 돌리지 않는다는 것을 확인하고 기준선을 건드리지 않는다(아래 5절 K 행).
7. **권한 칩 라벨**: `tools.permissionMode` 가 설정된 에이전트의 칩이 실제보다 넓게(전체 액세스) 표시되던 것을 좁은 쪽으로 고친다.
8. **사용자 표 역할 빈칸**: 4번에 포함.
9. **감사 표 세션 열 잘림**: 폭 상한·말줄임·`title` 전체 값.
